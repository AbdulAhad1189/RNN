# RECURRING

An interactive visual journey through recurrent neural networks, grounded in Jeffrey L. Elman's “Finding Structure in Time” (1990).

## Why I made this

Research papers are essential, but they can be difficult to approach when an idea is introduced through dense academic language, equations, and static diagrams. I wanted to make the core idea of recurrence easier to experience: a network receives a sequence, carries context forward, and uses what came before to shape what comes next.

RECURRING turns that idea into a paced, chapter-based visual story. Each chapter asks the visitor to spend a short reading interval before a small, varied swipe or scroll cue appears. The warm paper palette, animated diagrams, 3D recurrent-cell visualization, and small interactions make the concepts easier to follow while keeping the original research and its limits visible. It is an educational companion to the paper, not a replacement for reading it.

The project builds up the vanilla RNN first: sequence inputs, hidden state, shared weights, outputs, loss, and backpropagation through time. It then explains vanishing and exploding gradients as learning difficulties, before introducing LSTM and GRU as later gated recurrent designs. It distinguishes Elman's 1990 work from later research and labels explanatory examples and generated data clearly. Scroll and touch gestures advance only after the chapter's reading interval; keyboard arrows are available as an accessible alternative.

## Run locally

Requirements: Node.js 20.9+ and Python 3.10+. Install dependencies with `npm install`, then start the site with `npm run dev`. Visit `http://localhost:3000`. Create a production build with `npm run build`, then serve it with `npm start`.

The checked-in JSON makes the experience run without Python. To regenerate the scalar teaching curves and the fixed nonlinear PyTorch autograd experiment as JSON/CSV, install PyTorch (`python -m pip install torch`) and run `npm run data`. To recreate the six notebooks, run `python research/experiments/create_notebooks.py`.

## Structure

- `app/`: App Router, global design system, page narrative
- `components/`: reusable scene, motion, SVG network and interactive experiment components
- `research/experiments/`: data-generation script
- `research/notebooks/`: six small notebooks for forward recurrence, hidden states, BPTT, gradient decay, sequence prediction, and LSTM comparison
- `research/data/`: checked-in JSON and CSV outputs; `autograd_gradient.*` records the fixed scalar tanh recurrence derivatives generated by PyTorch autograd

## Research boundaries

The experience distinguishes Elman's 1990 proposal and simulations from later accounts of backpropagation through time, long-term dependency learning difficulties, and LSTM. In the interactive chart, the solid line is a synthetic scalar recurrence and the dashed line is a fixed PyTorch autograd experiment on a scalar tanh recurrence. Neither is a result reported by Elman or a complete trained RNN gradient model. See the final research section for primary source links.

## Motion, access, and performance

The recurrent cell uses CSS 3D transforms, with no WebGL dependency, and remains understandable without animation. The experience honors `prefers-reduced-motion`, uses semantic headings, keyboard navigation, visible focus indicators, and a live value announcement for the gradient demonstration. Gestures have a keyboard alternative. There are no external fonts, large image downloads, or autoplay media.

## Deployment

Deploy as a standard Next.js Node application on Vercel or another Node host. Use `npm run build` in the build step and `npm start` as the server command. Node.js 20.9 or newer is recommended by current Next.js documentation. For a custom host, set the usual `PORT` environment variable and bind the Next server as required by the host.

## Checks

Run `npm run build` for a production compilation. Review at desktop, tablet, and mobile widths; test with keyboard only and with the operating-system reduced-motion preference enabled. No automated browser-test suite is included.
